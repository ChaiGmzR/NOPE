# Changelog

## 0.2.0 — 2026-09-14

- La pantalla de foco permanece visible durante toda la sesión y muestra una
  vista dedicada durante las pausas.
- El requisito de pausa aumenta a diez retos aleatorios.
- Se agregan Sudoku 4 × 4, sopa de letras y une los puntos.
- Authenticator queda disponible cuando se detecta una aplicación compatible.
- Nuevo reloj de arena con cámaras, flujo y nivel de arena progresivo.
- Las tintas Monocromo, Azul tinta y Bosque ahora modifican de forma visible la
  pantalla de foco y los estados seleccionados.

## 0.1.0 — 2026-09-14

Primera versión pública de NOPE.

- Bloques rápidos y horarios recurrentes de enfoque.
- Protección Android con lista de aplicaciones esenciales.
- Cinco retos para conceder una pausa temporal.
- Relojes digital, analógico y de arena.
- Calendario, cumplimiento, racha e interrupciones.
- Temas claro/oscuro y paletas ajustables.
- Actualizaciones desde GitHub Releases con validación SHA-256.
